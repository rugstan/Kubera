# Kubera Commercial build plan (agent spec)

This file is the single source of truth for every build agent. Read the **Global rules**, the **Reference** section, and your own **workstream** section before writing code. The approved plan document this is derived from: https://claude.ai/artifact/BeHxabmLTZoGBNihimkcYo (revision 5).

## Product in one paragraph

Kubera Commercial, Inc. is a California DRE-licensed real estate corporation that **brokers** commercial real estate loans (it is never the lender). Programs: HUD 232/223(f) and 232 new construction, SBA 504 and 7(a) (incl. a 7(a)+504 stack), hotel CMBS, PIP bridge, HUD 223(f)/221(d)(4)/223(a)(7) multifamily, Fannie/Freddie agency, bank/life co, private bridge, hard money and construction. Sites: `kuberacommercial.com` (full site) and `kubera.loans` (60-second qualifier only, routed by `proxy.ts`). Today the repo has: marketing homepage, rate ticker (FRED), three-tab loan sizer (`lib/sizing`), Jev rules engine (`lib/ai/jev.ts`), Claude advisor + ⌘K command bar (`lib/ai/advisor.ts`, `components/ask`), express qualifier, partner portal, Twenty CRM REST client (`lib/crm/twenty.ts`), Supabase schema + private document vault (`supabase/migrations/20261031000000_init.sql`), API routes under `app/api/*`.

## Global rules (apply to every workstream)

1. **Broker only.** No code path may accept, hold, transfer or disburse money (borrower, investor or construction draw funds). Kubera has **no role in construction draws** — no draw pre-checks, lien waivers, draw inspections or draw servicing. Kubera never services loans. Private lenders fund as **lender of record**; never model Kubera as lender, originator of record or trust-deed beneficiary.
2. **Approval gate.** Every outbound action an agent or workflow takes (email, SMS, lender submission, e-sign send, CRM stage/owner change, any third-party write) must pass the broker approval gate (`approvals` queue built by WS-I/AB). Only templates a broker pre-approved may send automatically. A timed-out approval **expires and never sends**.
3. **Integrations are env-gated.** Every external service lives behind a typed client in `lib/<service>/` with an interface, a real implementation and an in-memory fake for tests. Missing keys → log once and no-op/degrade; never crash a build or a page. Add every env var to `.env.example` with a one-line comment. Never commit secrets.
4. **Legal and compliance copy.**
   - Drafted legal pages (privacy, terms, licensing, accessibility, disclosures) carry a visible `DRAFT — pending counsel review` notice whenever `NEXT_PUBLIC_LEGAL_APPROVED !== "true"`.
   - Never state that a specific loan is usury-exempt. Never guarantee a closing timeline ("many close in 10–21 days after a complete file, subject to … ; not guaranteed").
   - Loan advertising shows `licenseLine()` from `lib/site.ts` (includes "Real estate broker, California Department of Real Estate" and the DRE license numbers).
   - Copy positioning: "advisor-led, AI-assisted" — not "autonomous". No "approved", "qualified for", "fees protected", "will call you today".
5. **Design.** Apple-style aesthetic already in `app/globals.css` (canvas, bento cards, glass header, Inter/SF). Accent tokens are set by WS-C; after Phase 0 use the token names, never raw hex. WCAG 2.2 AA: contrast ≥ 4.5:1 for text, visible focus, keyboard reachable, `prefers-reduced-motion` honored (`MotionConfig reducedMotion="user"`).
6. **Next.js 16 specifics.** `proxy.ts` (not `middleware.ts`). `cacheComponents: true`: anything dynamic must be inside `<Suspense>` or a `"use cache"` function; `new Date()`/`Date.now()` in server components must sit inside a cached function. `revalidateTag(tag, profile)` takes two args. Route handlers in `app/api/**/route.ts`. When unsure, read `node_modules/next/dist/docs/`.
7. **Claude API.** `@anthropic-ai/sdk`. Default model `claude-opus-5-5`; `claude-sonnet-5-5` for mid-tier and `claude-haiku-5-5` for cheap bulk classification. Use `client.beta.messages.stream` + `.finalMessage()`, `betas: ["server-side-fallback-2026-07-01"]`, `fallbacks: "default"`, `output_config: { effort }`. Never send `temperature`, `top_p`, `budget_tokens`, `thinking: {type:"disabled"}`, assistant prefill, or forced `tool_choice` (`any`/`tool` → 400); use `tool_choice: auto` + `strict: true` tools or `output_config.format` for structured output. Check `stop_reason === "refusal"`. Lazy-init the client (no constructor at module load).
8. **Data.** Supabase Postgres. Every new table: RLS enabled; service role only unless WS-I defines portal policies. Migrations: `supabase/migrations/<timestamp>_<ws>_<name>.sql` where the timestamp block is per phase and the minute is per workstream (Phase 0 `2026110100MM00`, Phase 1 `2026110200MM00`, Phase 2 `2026110300MM00`, Phase 3 `2026110400MM00`, Phase 4 `2026110500MM00`; MM = the workstream's slot listed in its section). Never edit an existing migration. Known exceptions to the slot pattern (already applied, so not renamed): WS-E `20261101050000_e_crm_retry.sql` and `20261101050100_e_crm_progress.sql` (the pattern gives `20261101000500`), and WS-P `20261105010000_p_growth.sql` (the pattern gives `20261105000100`). `scripts/test-migrations.ts` rejects any other workstream migration whose timestamp does not match `2026110P00MM00`, with these three files allowlisted; `init` and integrator `int_*` fixes are exempt. PII columns (SSN, DOB, account numbers) are encrypted at the application layer once WS-Y lands (`lib/privacy/crypto.ts`).

### Legal research findings to implement (gates A and H; attorney sign-off pending)
- **MLDS (gate A):** an **RE 882** Mortgage Loan Disclosure Statement is required on **every** loan Kubera brokers that is secured directly or collaterally by any lien on real property, at any size, from any lender (B&P §10240; §10245 carve-back). Trigger: `collateral_includes_real_property && kubera_role = 'broker'`. Clock starts when Kubera receives a **completed written loan application**; due by the earlier of **3 business days** or before the borrower becomes obligated. Fields per §10241/RE 882: estimated maximum borrower-paid costs (appraisal, escrow, title, notary, recording), **all** broker compensation incl. lender-paid, loan terms and payments, credit insurance not required, broker-controlled funds will not be used, Kubera name/license #/licensed address, estimate notice. Signed by each borrower and by Kubera's broker or a licensee for the broker; borrower gets an exact copy; e-signature OK (capture UETA consent); retain **3 years**. Hard blocks: no commitment or loan document to the borrower before the MLDS is signed; no deal to `closing` without a signed MLDS; deals naming Kubera as beneficiary/originator → `held_for_counsel`. Paid referral where the lender negotiates → treat MLDS as required. Business-asset-only SBA 7(a) (no real-property lien) → no MLDS but flag `cfl_license_review`.
- **Usury / broker of record (gate H):** Civ. Code §1916.1 exemption requires a licensed Kubera broker who **actively arranges** the loan **for another**, for **paid or expected compensation**, on a loan secured by real property. Since 2025-01-01 (SB 1146) each **forbearance, extension or modification** must itself be arranged by a licensed broker. Record on every loan and every modification: arranging DRE licensee (name, license #), party Kubera acts for, engagement/fee agreement, compensation amount and payer, negotiation log (term-sheet versions, communications), lender name and exempt-lender category, collateral (real-property lien, APN, position; equity-pledge/UCC-only ⇒ `usury_exemption_unavailable`), business-purpose certification, designated-officer approval. Gates: non-exempt lender + rate above the Cal. Const. art. XV cap ⇒ block until all elements recorded and officer approves; modification negotiated only by a lender/servicer ⇒ `no_exemption_representation` + written notice to lender; pre-2025 modifications and table-funded deals naming Kubera ⇒ counsel. The CFL broker exemption is Fin. Code **§22057**. §10236.7 applies only to multi-lender/securities deals (not built). AB 2116 (commercial financing licensing) is operative in 2028 — note only.
- Advertising: 10 CCR §2847.3 statement + license # on loan ads (already in `licenseLine()`).

### HUD multifamily values (WS-V; mark `VERIFY` with source + as-of date)
Market-rate 223(f) and 221(d)(4): **87% LTV/LTC, 1.15x DSCR** (HUD Mortgagee Letter 2025-03, Jan 2025). Affordable / rental assistance: **90%, 1.11x**. 221(d)(4) middle-income tier: single source, keep behind a flag. MIP: **flat 0.25%** for FHA multifamily applications on/after 2025-10-01 (Federal Register, Sept 23, 2025); upfront premium configurable (default 0.25%, VERIFY). Green certification no longer lowers MIP. Section 232 is **not** changed by ML 2025-03 (keep 80% / 1.45x; MIP 0.65% refi, 0.77% NC — VERIFY whether the 0.25% notice reaches 232).

### Other program facts (from research; treat as defaults, mark VERIFY)
- Agency: Fannie Small (≤$9M) 80% / 1.25x / 30-yr am, terms 5–30 yrs; Freddie "Conventional Small" $2–10M 80% / 1.25x (Freddie SBL reportedly retired 2026-04-15). Real deals average ~63% LTV / 1.43x — DSCR usually binds.
- Bridge exit test: stabilized debt yield 9.5–10.5% and 1.25x. Hard money: 9.5–12.5% rates, 1–4 points, 65–75% LTV/LTARV (fix-and-flip), up to 80–85% on stabilized bridge, 6–36 mo IO, extensions 0.5–2%, minimum interest 3–6 mo, exit fee 0.5–1%, default rate up to 24%. Construction: bank 60–65% LTC (SOFR+275–350), debt fund 65–75% LTC (SOFR+425–525), private 85–90% LTC capped at 70–75% of as-completed value, interest reserve inside the loan.
- California: AB 1482 cap 5% + regional CPI (max 10%), 15-year rolling new-construction exemption, Costa-Hawkins vacancy reset, City of LA RSO 3% (Jul 2026–Jun 2027). Prop 13 reassessment on sale at ~1% + local levies.
