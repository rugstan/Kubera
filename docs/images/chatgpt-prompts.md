# Site images: prompts to paste into ChatGPT

13 images in total. All are landscape photos of buildings, with no people, no cars and no text.

## How to do it

1. In ChatGPT, paste one prompt at a time (start a new chat if the style starts to drift).
2. Ask for **landscape, 1536 × 1024** (3:2). That is the widest size ChatGPT makes. If it offers a larger or HD landscape size, use that instead.
3. Download each image and give it the file name shown (for example `01-home-hero.png`).
4. Attach all 13 back here in one message (or a few messages), keeping the file names. I will crop each one to the shapes in the table, compress it, place it on the site and add the disclosure line.

If an image has any lettering, signs, logos, people or cars in it, ask ChatGPT to redo it. Those can't go on the site.
